## 2. Intent-to-Format Optimization Guidelines

1. **Informational Query ("What is...", "Why..."):**
   - Place a clear 40–50 word direct definition within the first 150 words of the page.
   - Follow immediately with a bulleted summary of 3–4 core characteristics.
2. **Comparison Query ("A vs. B"):**
   - Provide a structured HTML table with distinct evaluation dimensions.
   - Avoid generic superlative columns; focus on structural, environmental, and remedial differences.
3. **Procedural Query ("How to...", "Steps..."):**
   - Deploy ordered `<ol>` lists with bold phase titles.
   - Ensure steps are actionable without implying unauthorized civil construction work.
4. **Local / Transactional Query ("...in Bangalore", "...consultant near me"):**
   - Prominently feature the verified headquarters: _Dasarahalli, Bengaluru, Karnataka 560024_.
   - Detail specific service neighborhoods (Indiranagar, HSR Layout, Koramangala, Whitefield) while preserving single-entity clarity.
