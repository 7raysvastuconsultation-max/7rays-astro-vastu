## 1. CORE PRIVACY COMMITMENT

High-net-worth homeowners, corporate leaders, and individuals consulting 7Rays Astro Vastu share sensitive architectural, financial, and personal details. Protecting this data is an ethical mandate.

No client information, photograph, floor plan, or quotation may ever be published without explicit, verifiable consent.

---

## 2. TIERED CONSENT FRAMEWORK

7Rays offers clients four distinct levels of case documentation privacy:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        TIERED CONSENT LEVELS                           │
├─────────────┬──────────────────────────────────────────────────────────┤
│ Level 1     │ 100% Anonymous (Default)                                 │
│             │ • "3BHK Apartment in North Bengaluru"                    │
│             │ • No client name, no society name, no exact unit #       │
│             │ • Redacted CAD diagram without architectural labels      │
├─────────────┼──────────────────────────────────────────────────────────┤
│ Level 2     │ Generalized Corporate / Locality Disclosure              │
│             │ • "Fintech Enterprise Hub, HSR Layout, Bengaluru"        │
│             │ • Discloses general industry and commercial neighborhood │
│             │ • Client company name redacted                           │
├─────────────┼──────────────────────────────────────────────────────────┤
│ Level 3     │ Verified Corporate Attributed Case Study                 │
│             │ • Discloses company name and corporate executive title   │
│             │ • Requires written sign-off from corporate communications │
├─────────────┼──────────────────────────────────────────────────────────┤
│ Level 4     │ Fully Confidential (Zero Publication)                    │
│             │ • Case study documentation strictly withheld from public │
│             │ • Remains exclusively in internal client records         │
└─────────────┴──────────────────────────────────────────────────────────┘
```

## 3. SPECIFIC ASSET CONSENT MATRIX

| Asset Type                       | Standard Treatment                                                  | Condition for Public Use                                                            |
| -------------------------------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **Client Legal Name**            | Redacted by default (e.g., "Mr. S.K.")                              | Written consent required to use full name.                                          |
| **Property Address**             | Unit number and floor number permanently redacted                   | Disclose only neighborhood/zone (e.g. "Hebbal, Bengaluru").                         |
| **Architectural Floor Plans**    | All client personal names, room sizes, and title blocks scrubbed    | Vector CAD diagram showing directional zones only.                                  |
| **Interior Photographs**         | Personal family photos, portraits, and valuables cropped or blurred | General room perspective showing lighting and spatial flow only.                    |
| **Client Testimonials / Quotes** | Published only with direct written or WhatsApp confirmation         | Review excerpts from public Google Maps may be attributed to public profile handle. |
| **Astrological Data**            | Exact birth date, hour, minute, and birthplace strictly protected   | Never published in association with identifiable personal names.                    |
