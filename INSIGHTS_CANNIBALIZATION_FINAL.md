## 1. Executive Summary

Keyword cannibalization occurs when multiple URLs within a domain target identical or nearly identical primary search intents, confusing search engine indexing algorithms and cannibalizing click-through rates.

Following our complete content rebuild in `src/data/blog.ts`, every Insights article has been assigned a single, uncompromised topical boundary. This document audits every potentially adjacent article pair across titles, H1s, keyword themes, search intent, internal anchor text, and commercial routing.

## 4. Internal Link Anchor Text Audit

To prevent internal anchor text cannibalization, all cross-article links use natural semantic anchors rather than exact-match phrases:

- **Apartment Articles** link to `/vastu/apartment-vastu` using _"specialized apartment Vastu consultancy"_ or _"high-rise flat layout assessment"_.
- **Homeowner Articles** link to `/vastu/residential` using _"residential villa Vastu consultation"_ or _"comprehensive 16-zone house planning"_.
- **Home Office Articles** link to `/vastu/office-vastu` using _"workplace ergonomic and commercial Vastu solutions"_.
- **Remedial Articles** link to `/vastu/non-demolition` using _"non-demolition metallic wire bounding"_ or _"non-invasive spatial corrections"_.
- **Astrology Articles** link to `/astrology/birth-chart` using _"personalized Janam Kundli analysis"_ and to `/astrology/career` using _"professional astrological timing"_.
